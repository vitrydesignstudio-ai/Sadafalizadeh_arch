# Sadaf Alizadeh Platform — Site Architecture v0.7

## Main structure

- Home / Profile

- Studies
- Digital Tools
- Education
- Support
- Contact
- User Account

Digital Tools is the marketplace layer. Items can be:

- Free
- Paid

Categories:

### AutoCAD

- Templates

### Photoshop
- Brushes
- Presets
- Post-production resources

### 3ds Max
- Scripts
- Plugins
- Materials
- Models

### Lumion / D5 Render
- Assets
- Presets
- Workflows

Users can register/login with:

- Email
- Phone number

After login, language preference is selected:

- Persian
- English
