# Sadaf Alizadeh Website Architecture v2

## Main Navigation

- Home
- Portfolio
- Academy
- Digital Tools
- About
- Contact
- Account

## Portfolio

Portfolio is client-facing. Projects are managed from the admin panel.

Project fields:
- Title
- Cover image
- Gallery
- Location
- Year
- Area
- Category
- Description
- Concept
- Process
- Final images

No demo projects should be published by default.

## Digital Tools

Digital Tools replaces a simple store concept. It contains free and paid resources.

Structure:

Digital Tools

- AutoCAD
  - Scripts
  - Blocks
  - CTB
  - Templates
  - Free Resources

- 3ds Max
  - Scripts
  - Models
  - Materials
  - Scenes

- Corona Renderer
  - Materials
  - Presets
  - HDRI

- Photoshop
  - Brushes
  - Actions
  - PSD Templates
  - Materials

- Lumion
- D5 Render
- AI Tools
  - Prompts
  - Workflows
  - Video Tools

Each product supports:
- Free / Premium status
- Price
- Version
- License
- Download file
- Update history
- Images
- Description

## Account System

Users can register and login with:

- Email + Password
- Mobile + Password

First login language preference:

- Persian
- English

Saved in user profile and changeable later.

Account dashboard:

- Profile
- Downloads
- Purchases
- Licenses
- Support Tickets
- Project Requests
